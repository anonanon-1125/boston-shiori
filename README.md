# ボストン栞（11月のボストン）

2026.11.6–11.29 のボストン滞在の栞サイト。ビルドなしのHTML/CSS/JSなので、pushすればそのままGitHub Pagesで公開されます。

## どのファイルを触ればいいか

| ファイル | 中身 | 触る頻度 |
| --- | --- | --- |
| `plan.js` | 予定・文章・カレンダーの印・ポーツマス・記念日・おでかけスポット・暮らしのメモ | よく触る |
| `photos.js` | 写真の一覧とクレジット | 写真を替えるとき |
| `photos/` | 写真ファイル（1080px程度に縮小済み） | 写真を替えるとき |
| `index.html` | ページの骨組み（章の見出しなど） | ほぼ触らない |
| `style.css` | 見た目。色は先頭の `:root` で一括変更 | たまに |
| `app.js` | 描画の仕組み | 触らなくてOK |
| `sw.js` | 圏外でも見られるようにする仕組み | 触らなくてOK |
| `credits.html` | 「このしおりについて」ページ（写真のクレジット・ホーム画面への追加・PDFのしかた） | 触らなくてOK |

## ローカルで見る

```bash
python3 -m http.server 8765
```

ブラウザで http://localhost:8765 を開く。`plan.js` に書き間違いがあると、ページ上部に赤いお知らせ（ファイル名と行番号つき）が出ます。

## 予定の直し方（例）

- 日帰り先が決まった → `plan.js` の `week3` の「電車で日帰り」で、`choices` の片方を消し、`tags: ["未定"]` を外す
- ホテルが決まった → `PORTSMOUTH` に `hotels: [...]` を足すと「泊まるところ」が出る（書き方は plan.js のコメント）
- おでかけスポットを足す → `SPOTS.groups` の `items` に1つ追加。`solo: true` で「ひとりでもOK」、`map` は場所名（住所は書かない）
- ツリー点灯日が出た → `when: "日にち 未定"` を `date: "11-21"` などに。カレンダーにも出したければ `cal: "ツリー"`
- 記念日の準備ができた → `ANNIVERSARY.prep` の `done: true`
- 直したら `TRIP.updated` の日付も更新（ページ下に「最終更新」として出ます）

曜日は日付から自動で付きます。「きょう」の印も自動です。

表紙右上の「PDFがほしいなら」を押すと、写真を全部読み込んでから印刷画面が開きます（A4、章ごとに改ページ）。iPhoneでは印刷画面の共有ボタン →「ファイルに保存」でPDFになります。

## 写真を自分たちのものに替える

```bash
python3 tools/prep_photo.py ~/Desktop/IMG_1234.HEIC w2-library
```

`photos/w2-library.jpg` が縮小・圧縮されて上書きされます（HEICも可。位置情報などのメタデータは消えます）。そのあと `photos.js` の `"w2-library"` の `credit:` 行を消せば、ページ下のクレジットからも消えます。

トリミング位置は `photos.js` で `pos: "50% 30%"`（横 縦）を足して調整できます。アイコンを作り直すときは `python3 tools/make_icons.py`。

## 更新するとき

```bash
git add -A
git commit -m "予定を更新"
git push
```

反映まで1〜2分、スマホ側のキャッシュで最大10分ほどかかることがあります。ホーム画面から開いている場合も、開き直せば最新になります。

## iPhoneでホーム画面に追加

1. **Safari** でURLを開く（LINEのリンクから開いた場合は、右下のメニューから「Safariで開く」）
2. 共有ボタン →「ホーム画面に追加」
3. 「ボストン栞」のアイコンで、アプリのように全画面で開けます。一度開けば、電波がないところでも見られます。

## 写真について

`photos/` の写真は Wikimedia Commons と Flickr のもの（CC BY / CC BY-SA / CC0 / パブリックドメイン）を縮小・圧縮して使っています。Boston Lights の写真は、ほかの会場のランタン展の「イメージ」です。作者とライセンスは `photos.js` にあり、ページ下部に自動で表示されます。
